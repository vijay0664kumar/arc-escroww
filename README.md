# Arc Escrow V2

A non-custodial onchain escrow application built on **Arc Testnet**.

Create, fund, complete, and settle escrow agreements directly through smart contracts.

## Live Demo

https://soft-jalebi-0de10e.netlify.app/

## Features

- Non-custodial escrow
- Multi-token support
- 0.5% protocol fee
- Escrow status tracking
- Search and filtering
- Onchain activity history
- Shareable escrow links
- Transaction notifications
- Refund and cancellation flows
